# TRANSITX — Course Syllabus Mapping

**Course**: Data Science Ecosystem (Course Code: 23CS2024)  
**Academic Level**: 3rd Year B.Tech Computer Science and Engineering (L T P C: 3 0 0 3)

| Syllabus Module | Official Syllabus Topics | TRANSITX Practical Implementation |
| :--- | :--- | :--- |
| **Module 1: Basics of Data Science** (7 Hours) | Introduction to Data Science, properties of data, exploring datasets from various repositories, toolboxes for data scientists. | • Problem formulation for urban transit analytics.<br>• Ingestion of multi-corridor transit datasets.<br>• Full Python, FastAPI, Pandas, Leaflet, and React ecosystem tooling. |
| **Module 2: Understanding Data** (8 Hours) | Working with data: Import, select, filter, manipulate, sort, group, rearrange, rank, analyze for missing data values, data visualization. | • Data Explorer with multi-column filtering and pagination.<br>• Median and mode missing-value imputation pipeline.<br>• Corridor and station ranking by volume and headway delay. |
| **Module 3: Statistical Inference** (8 Hours) | Descriptive statistics (Mean, Median, Variance, Std Dev for small/large datasets), EDA, correlation between variables, estimation, Hypothesis Testing (Null and Alternative hypotheses). | • Comprehensive summary statistics with distribution histograms.<br>• Pearson & Spearman correlation coefficient matrix.<br>• Two-Sample Welch's t-test ($H_0$ vs $H_1$, $t$-stat, $p$-value, Cohen's $d$). |
| **Module 4: Machine Learning** (8 Hours) | Introduction to ML, regression (Linear, Multiple), clustering (Similarity & distance measures, K-Means clustering, Agglomerative clustering), model evaluation. | • Simple & Multiple Linear Regression ($R^2$, MAE, RMSE).<br>• K-Means corridor clustering ($k=2,3,4$) with Silhouette validation.<br>• Statistical Z-Score Anomaly Detection ($|Z| > 2.5$). |
| **Module 5: Recommender System** (7 Hours) | Content-based filtering, collaborative filtering, similarity/distance measures, evaluating recommenders. | • Content-based transit corridor recommender using normalized vector Cosine Similarity across ridership, rush volume, and delays. |
| **Module 6: Ethics in Data Science** (7 Hours) | Privacy and confidentiality, anonymization & de-identification, bias and fairness, transparency and accountability, explainability and model interpretability. | • Hourly data aggregation with zero PII retention.<br>• Sampling bias awareness across automated vs manual fare stations.<br>• Non-prescriptive, explainable operational interpretations. |
